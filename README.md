# Vibe coded StarCraft II Bot

Project create based on [python-sc2](https://github.com/BurnySc2/python-sc2) library

## MVP

The bot should:

- [ ] Create new units
- [ ] Redistribute units
- [ ] Upgrade the structures
- [ ] Upgrade the units
- [ ] Make a army
- [ ] Attack the enemy

The goal is to make a bot that follow a predefined strategy
